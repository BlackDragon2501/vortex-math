# Vórtex Math

Vórtex Math, de Vortex Company: calculadora científica con grados/radianes, teclado en pantalla e historial de sesión, más graficador 2D de hasta 6 funciones `f(x)` simultáneas con zoom, paneo por arrastre, detección de discontinuidades y rejilla inteligente. Parser propio y dibujo en Canvas, sin librerías externas. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- Parser de expresiones propio (sin Math.js ni dependencias)
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
